# Fluento

App web per imparare l'inglese vero, dalle basi (A1) fino al livello madrelingua (C2).

## Come usarla

Apri il link della pagina pubblicata con GitHub Pages direttamente dal browser del telefono (Safari su iPhone, Chrome su Android):

👉 **https://8rrm7tvzcf-droid.github.io/Fluento/**

Per averla come un'app sulla schermata Home:
1. Apri il link qui sopra nel browser.
2. Tocca l'icona di condivisione.
3. Scegli "Aggiungi a Home" (iPhone) o "Installa app" (Android).

## Cosa contiene

- 12 lezioni, dal livello A1 al C2, sbloccate una alla volta
- Vocabolario con flashcard e ripetizione dilazionata (sistema Leitner)
- Grammatica spiegata con esempi ed esercizi
- Quiz a scelta multipla
- Esercizi di ascolto con sintesi vocale
- Laboratorio di pronuncia con riconoscimento vocale (dove supportato dal browser)
- Streak giornaliero, punti XP e traguardi

## Note tecniche

Pagina singola in HTML/CSS/JavaScript, nessuna dipendenza esterna oltre ai Google Fonts e alle API vocali del browser. Il progresso viene salvato nella memoria locale del browser (`localStorage`) del dispositivo su cui viene aperta.
